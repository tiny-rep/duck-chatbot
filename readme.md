# 🦆 Duck-Chatbot 智能应用平台

> 专为行业场景打造的 **AI Agent 智能对话平台**，支持多端访问，快速落地企业级智能助手。

---

## 📌 项目简介

Duck-Chatbot 是一个面向行业场景的智能应用平台，支持快速构建和部署对话式 AI 应用（如安全监控数据洞察、设备运维助手、产品参数问答等）。
平台采用统一后端服务，同时提供 **H5、原生APP、微信小程序** 三种移动端入口，让用户随时随地访问智能服务。

---

## ✨ 核心亮点

- 🌐 **多端统一体验**
  一套服务，三端入口：H5 / 原生APP / 微信小程序，数据实时同步，体验一致。
- 🤖 **行业级对话能力**
  内置智能体（Agent）流程编排，支持工具调用、标准规范解读、数据诊断分析。
- 📊 **场景化应用模板**
  可快速搭建安全监控、环境监测、设备运维、产品助理等行业场景应用。
- 🔌 **灵活扩展**
  支持自定义工具、接口对接、多轮对话流程配置，满足复杂业务需求。
